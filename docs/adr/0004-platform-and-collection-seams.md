# ADR-0004：平台能力与采集运行 seam

- 状态：已接受
- 日期：2026-07-15

## 决策

平台共同信息集中为平台能力声明；Electron 中保留每个平台的采集 adapter。手动、托盘、应用内定时和系统计划任务必须通过同一个采集运行模块。

## 原因

四个平台已有不同响应格式，多个 adapter 证明 seam 真实存在；但 URL、身份、视觉和采集能力若散在调用者中，会使平台能力漂移。多个采集入口若各自编排，会造成预检、错误和统计不一致。

## 后果

- 新增平台必须同时提供能力声明和所需 adapter。
- 调用者只能提交采集请求并消费进度/结果，不复制平台循环和预检规则。
- adapter 的公共契约是平台采集测试面。

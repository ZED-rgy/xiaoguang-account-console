# ADR-0002：账号提升与稳定身份

- 状态：已接受
- 日期：2026-07-15

## 决策

添加账号使用独立登录会话。只有同时取得可用昵称、头像以及至少一个稳定身份后，登录会话才能提升为正式账号。合并优先使用平台账号 ID，其次使用归一化公开主页 URL；昵称不参与唯一性判断。

## 原因

昵称可重复、可变化，也可能来自页面中的其他作者。临时登录状态进入正式表会污染账号数量、分析和采集目标。

## 后果

- 临时浏览器分区在提升后由正式账号采用。
- 提升、合并、采集目标加入和临时会话删除必须位于同一数据库事务。
- 异常退出必须清理未采用的登录会话和浏览器分区。
